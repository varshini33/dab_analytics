# Databricks Declarative Automation Bundles – Practice Project

## 📌 About the Project

This repository is a hands-on practice project for learning **Databricks Declarative Automation Bundles (DABs)**.

The goal is to understand how to organize Databricks project files, configure resources, and manage deployment workflows using bundles.

## 🎯 Learning Objectives

- Understand the basics of Databricks Declarative Automation Bundles.
- Explore the structure of a Databricks project.
- Learn how to configure bundle resources and deployment settings.
- Practice validating, deploying, and running Databricks resources.
- Understand how GitHub can be used to manage project code and workflows.

## 🛠️ Tools & Technologies

- **Databricks** – Data engineering and analytics platform
- **Databricks CLI** – Command-line interface for working with Databricks
- **Declarative Automation Bundles (DABs)** – Project configuration and deployment management
- **Git & GitHub** – Version control and project management
- **YAML** – Bundle configuration

## 📂 Project Structure

```text
dab_analytics/

│   └── workflows/          # GitHub workflow configurations
├── bakehouse_analytics/    # Databricks project files
└── README.md               # Project documentation
```

## 🚀 What I'm Practicing

- Setting up a Databricks bundle project.
- Understanding the `databricks.yml` configuration.
- Managing Databricks resources through configuration files.
- Validating bundle configurations.
- Deploying and running resources in a Databricks workspace.
- Exploring automated workflows using GitHub Actions.

## 🎓 Purpose

This is a learning project created to gain practical experience with Databricks project organization, configuration, and deployment workflows.
